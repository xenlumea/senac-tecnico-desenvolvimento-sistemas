Tutorial do Fluxograma

Símbolo Nome Descrição Portugol / HTML / JS
START INDICA O INÍCIO DO PROGRAMA PORTUGOL: programa{funcao inicio(){} }
HTML: <!DOCTYPE html> <html> </html>
JS: Basta criar um arquivo .js e ligar ao HTML
TERMINATOR INDICA O FIM DO PROGRAMA PORTUGOL: programa{ funcao inicio(){ /*INSTRUÇÕES AQUI*/ } }
Chaves de fechamento da instrução programa e da função inicio
HTML: <!DOCTYPE html> <html> </html>
JS: Final da última linha do script.
CONNECTION INDICA O FLUXO DO PROGRAMA PORTUGOL, HTML JS: Executado da direita para esquerda, de cima para baixo.
DECISION INDICA UMA ESTRUTURA CONDICIONAL PORTUGOL: se (condição) { instrução1 } senao { instrução2 }
HTML: Não possui estruturas de decisão.
JS: if (condição) { instrução1 } else { instrução2 }
DISPLAY Mostra na tela uma informação PORTUGOL: escreva()
HTML: Qualquer tag visível h1, p, div, etc.
JS: console.log() alert()
PROCESS INDICA PROCESSAMENTO, DECLARAÇÃO DE VARIÁVEIS, CÁLCULOS, ETC... PORTUGOL: inteiro x = 10/5 , funcao(){}
HTML: Não faz processamento
JS: const x = 10; let y = x + 5; function exibe(){ console.log( x , y) }; exibe();
MANUAL INPUT INDICA A INSERÇÃO DE DADOS PELO USUÁRIO DO PROGRAMA. PORTUGOL: leia()
HTML: < input type="text" > < input id-"email" type="email" >
JS: Window.confirm( ); Window.prompt( ); , Captura valor de inputs HTML document.getElementById('email').value;
